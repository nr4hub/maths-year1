Why learn this for Python?

🎓 Why your university teaches this

Your university teaches this maths in the first-year Software Development module to support the Python programming module. A matrix is how Python (and NumPy, pandas and machine-learning libraries) stores and processes tables of numbers.

💻 Software engineering
  • Images, game boards and spreadsheets are matrices in memory
  • Graphics and game engines transform every point with matrix multiplication
  • Neural networks are mostly matrix multiplication
  • Database tables and DataFrames are tables of data, just like matrices
🛡️ Cybersecurity
  • Classical ciphers such as the Hill cipher encrypt with matrices
  • Networks are stored as adjacency matrices to show which hosts can reach which
  • Intrusion-detection models read rows of numeric features from traffic logs
  • Image forensics and steganography work on pixel matrices

Overview

A matrix is a rectangular grid of numbers. In software engineering you meet them everywhere: transforming points in graphics and games, storing neural-network weights, representing graphs, and solving systems of equations.

You will learn
  • Notation and matrix types
  • Add, subtract, scale, transpose
  • Multiply matrices
  • Determinants and inverses
  • Solve linear systems
How to study
  • Use the Matrix lab to check every hand calculation
  • Do the quiz for instant feedback
  • Attempt the sample test on paper first
🐍 Why this matters for Python

In Python a matrix is a list of lists. NumPy and pandas build on exactly this idea, so knowing the maths tells you what your code is really doing.

💻 Software engineering
  • Images, game boards and spreadsheets are matrices stored in memory
  • Machine-learning code is mostly matrix operations
🛡️ Cybersecurity
  • Ciphers and network maps are stored as matrices
  • Detection models read rows of numeric features from logs
🐍 Python example
A = [[2, 1],
     [0, 3]]
print(A[0][1])   # 1

Matrix (න්‍යාසය) යනු: සංඛ්‍යා පේළි (rows) සහ තීරු (columns) වශයෙන් සෘජුකෝණාස්‍රාකාරව සකස් කළ වගුවකි. සංඛ්‍යා පමණක් ඇති spreadsheet කොටසක් ලෙස සිතන්න. මෙම පාඩමේදී අපි matrix එකක් කියවන ආකාරය, එකතු කිරීම, අඩු කිරීම, ගුණ කිරීම, determinant, inverse, සමීකරණ විසඳීම සහ 2D රූප භ්‍රමණය ඉගෙන ගන්නෙමු.

Python සමඟ සම්බන්ධය: Python වල matrix එකක් ලියන්නේ list එකක් ඇතුළත list වශයෙනි (උදා: [[2,1],[0,3]]). ඉන්පසු NumPy, pandas වැනි library මගින් මෙම වගු ඉතා වේගයෙන් ගණනය කරයි. මෙම maths දැනගත් විට එම library එක ඇතුළත සිදුවන්නේ මොනවාදැයි ඔබට තේරුම් ගත හැක.

Software Engineering: රූපයක් යනු pixel වල matrix එකකි; game board එකක් සහ database table එකක් ද එසේමය. Machine learning වල ගණනය කිරීම් බහුතරයක් matrix ක්‍රියා වේ. Cybersecurity: encryption ක්‍රම, network සිතියම් සහ log වලින් ගන්නා සංඛ්‍යා දත්ත matrix ආකාරයෙන් ගබඩා කර විශ්ලේෂණය කරයි.

2

Basics & types

Brand new to this? Start here. Think of a matrix as a spreadsheet with only numbers. Rows run across (→), columns run down (↓). Always say row first, then column: “row 2, column 1” means go down 2, then across 1.
Reading a matrix
  • A = [[2,1],[0,3]] means row 1 is 2 1 and row 2 is 0 3.
  • Size is written rows × columns. Two rows and three columns = a 2×3 matrix (say “2 by 3”).
  • Each number is an entry. a21 = 0 means “row 2, column 1”.

A matrix with m rows and n columns has size m × n. The entry in row i, column j is written aij. Example: A = [[2,1],[0,3]] is 2×2, and a12 = 1.

TypeDefinitionExample
Squarem = n[[1,2],[3,4]]
Identity I1s on diagonal, 0 elsewhere; AI = IA = A[[1,0],[0,1]]
Zeroall entries 0[[0,0],[0,0]]
Diagonalnon-zero only on the diagonal[[3,0],[0,5]]
SymmetricAᵀ = A[[1,7],[7,2]]
Upper triangularzeros below the diagonal[[1,2],[0,3]]
Two matrices are equal only if they have the same size and all matching entries are equal.
🐍 Why this matters for Python

Row and column positions become list indexes. Python counts from 0, so maths 'row 1, column 2' is A[0][1].

💻 Software engineering
  • Reading and writing the right cell is the core of image, grid and table code
  • Off-by-one index mistakes are the most common bug here
🛡️ Cybersecurity
  • Adjacency matrix: entry (i, j) = 1 means host i can reach host j
  • Pixel grids are where hidden data is searched for in image forensics
🐍 Python example
A = [[1, 2, 3],
     [4, 5, 6]]
rows, cols = len(A), len(A[0])
print(rows, "x", cols)   # 2 x 3
print(A[1][2])           # 6  (maths: row 2, column 3)
සිංහල විස්තරය

Matrix එකක් කියවන ආකාරය: පේළි (rows) වමේ සිට දකුණට තිරස් අතට ඇති ඒවාය; තීරු (columns) උඩ සිට පහළට සිරස් අතට ඇති ඒවාය. ප්‍රමාණය (size) ලියන්නේ පේළි × තීරු ලෙසයි. පේළි 2ක් සහ තීරු 3ක් ඇති matrix එක 2×3 ලෙස කියවයි. a₂₁ යනු 2 වන පේළියේ 1 වන තීරුවේ ඇති අගයයි — සෑම විටම පළමුව පේළිය, ඉන්පසු තීරුව.

වර්ග: Square (පේළි = තීරු), Identity matrix (I — විකර්ණයේ 1 ද අනෙක් තැන් 0 ද), Zero matrix (සියල්ල 0), Diagonal, Symmetric (Aᵀ = A), Upper triangular. Identity matrix එක සාමාන්‍ය සංඛ්‍යා වල '1' හා සමානය: A × I = A. matrix දෙකක් සමාන වන්නේ ප්‍රමාණය සමාන වී සියලු අනුරූප අගයන් සමාන වන විට පමණි.

Python වලදී: Maths වල පේළි ගණන් කිරීම 1 සිට ආරම්භ වුවත් Python වල index 0 සිට ආරම්භ වේ. එබැවින් 'පේළිය 2, තීරුව 3' යනු A[1][2] වේ. rows = len(A), cols = len(A[0]) ලෙස ප්‍රමාණය ලබා ගත හැක. Index එක එකකින් වැරදීම (off-by-one) මෙහි සිදුවන සාමාන්‍ය දෝෂයකි. Cybersecurity: network එකක කුමන host එකට කුමන host එකට සම්බන්ධ විය හැකිද යන්න adjacency matrix එකකින් දක්වයි (i වන host එකට j වන host එකට යා හැකි නම් අගය 1 වේ).

Matrix lab එක භාවිතය: A සහ B matrix වල අගයන් වෙනස් කර, ක්‍රියාවක් (A + B, A × B, det, inverse ආදිය) තෝරන්න. ප්‍රතිඵලය සහ පියවරෙන් පියවර ගණනය කිරීම පහතින් පෙනේ. ඔබ අතින් කළ ගණනය කිරීම මෙයින් සසඳා බලන්න.

වැදගත් නීති: එකතු/අඩු කිරීම සඳහා matrix දෙකේම ප්‍රමාණය සමාන විය යුතුය. ගුණ කිරීමට A හි තීරු ගණන B හි පේළි ගණනට සමාන විය යුතුය. Determinant සහ inverse සඳහා square matrix එකක් අවශ්‍යයි. නීති කඩ වන විට tool එක 'not defined' ලෙස පෙන්වයි.

Python සඳහා වැදගත්කම: Program එකක් ලියන විට වැරදි ප්‍රමාණයේ දත්ත ලැබෙන අවස්ථා හඳුනාගෙන ඒවාට error message දිය යුතුය — මෙය input validation ලෙස හැඳින්වේ. ඔබේ Python function එකේ ප්‍රතිඵලය විශ්වාසදායක calculator එකක ප්‍රතිඵලයට සමානදැයි බැලීම manual testing වේ. Cybersecurity වලදී සංකේතන (encryption) කේතයේ එක් ගණිත වැරැද්දක් පවා පද්ධතිය අනාරක්ෂිත කරයි, ඒ නිසා ප්‍රතිඵල සත්‍යාපනය කිරීම අත්‍යවශ්‍යයි.

4

Add, subtract & scalar

The big idea: adding and subtracting matrices is just adding or subtracting matching boxes. If you can add two numbers, you can do this.
1. Addition: add the boxes in the same position

Line the two matrices up on top of each other. Box (1,1) pairs with box (1,1), box (1,2) with box (1,2), and so on. Add each pair.

Worked example: A + B

A = [[2, 1],[0, 3]]   B = [[5, 4],[2, 1]]

  • Top-left: 2 + 5 = 7
  • Top-right: 1 + 4 = 5
  • Bottom-left: 0 + 2 = 2
  • Bottom-right: 3 + 1 = 4

A + B = [[7, 5],[2, 4]]

2. Subtraction: same, but subtract

Take the box from the first matrix minus the box from the second. Order matters: A − B is not the same as B − A.

Worked example: A − B (same A and B)
  • 2 − 5 = −3   1 − 4 = −3
  • 0 − 2 = −2   3 − 1 = 2

A − B = [[−3, −3],[−2, 2]]

The size rule: you can only add or subtract matrices that are exactly the same size. A 2×2 plus a 2×3 has no matching boxes for the third column, so it is not defined. Think of it as trying to add a 4-seat table to a 6-seat table, seat by seat.
3. Scalar multiplication: multiply every box by one number

A scalar is just an ordinary number (like 2 or −3). To multiply a matrix by it, multiply every entry. The matrix size doesn’t change.

Worked example: 3A

A = [[2, 1],[0, 3]]

  • 3×2 = 6   3×1 = 3
  • 3×0 = 0   3×3 = 9

3A = [[6, 3],[0, 9]]

Combining them: do the scalar part first, then add or subtract. Example: 2A − B, with A and B as above: 2A = [[4,2],[0,6]], then subtract B = [[5,4],[2,1]] to get [[−1,−2],[−2,5]].

Rules that always hold
RuleIn words
A + B = B + AOrder doesn’t matter for addition (but it does for subtraction)
A + 0 = AAdding the zero matrix changes nothing
k(A + B) = kA + kBYou can distribute a scalar
A − A = 0Every box cancels to zero
Try it yourself
Press “New random problem”, work it out on paper, type your answer in the boxes, then check.
Common mistakes
  • Adding matrices of different sizes (always check sizes first).
  • Forgetting to multiply every entry by the scalar, not just the first.
  • Mixing up signs when subtracting a negative: 3 − (−2) = 5.
  • Doing A − B as B − A.
🐍 Why this matters for Python

Adding matrices is a nested loop or list comprehension that pairs up the cells in the same position.

💻 Software engineering
  • Blending two images or changing brightness is matrix addition and scalar multiplication
  • Game physics adds position and velocity values every frame
🛡️ Cybersecurity
  • Subtracting a baseline traffic table from today's table highlights anomalies
  • Combining log-count tables from several servers is matrix addition
🐍 Python example
A = [[2, 1], [0, 3]]
B = [[5, 4], [2, 1]]
C = [[A[i][j] + B[i][j] for j in range(2)] for i in range(2)]
print(C)                                    # [[7, 5], [2, 4]]
k = 3
print([[k * x for x in row] for row in A])  # [[6, 3], [0, 9]]
සිංහල විස්තරය

එකතු කිරීම: එකම ප්‍රමාණයේ matrix දෙකක් එකක් මත එකක් තබා, එකම ස්ථානයේ ඇති අගයන් එකතු කරයි. උදා: A = [[2,1],[0,3]] සහ B = [[5,4],[2,1]] නම් A + B = [[7,5],[2,4]] (2+5=7, 1+4=5, 0+2=2, 3+1=4). අඩු කිරීමේදී පළමු matrix එකේ අගයෙන් දෙවැන්නේ අගය අඩු කරයි; ඒ නිසා A − B සහ B − A වෙනස් ය.

ප්‍රමාණ නීතිය සහ scalar: ප්‍රමාණය වෙනස් matrix දෙකක් එකතු කළ නොහැක — ගැළපෙන කොටු නොමැති නිසා. Scalar ගුණ කිරීමේදී (උදා: 3A) matrix එකේ සෑම අගයක්ම එම සංඛ්‍යාවෙන් ගුණ කරයි; matrix එකේ ප්‍රමාණය වෙනස් නොවේ. සාමාන්‍ය වැරදි: සියලු අගයන් ගුණ කිරීම අමතක වීම සහ ඍණ ලකුණු (3 − (−2) = 5) වැරදි වීම.

Python සහ ක්ෂේත්‍රය: Python වලදී මෙය nested for loop එකකින් හෝ list comprehension එකකින් ලියයි. Software Engineering වලදී රූප දෙකක් මිශ්‍ර කිරීම හෝ රූපයක brightness වෙනස් කිරීම මෙම ක්‍රියා වේ. Cybersecurity වලදී සාමාන්‍ය දිනයක network traffic වගුවෙන් අද දිනයේ වගුව අඩු කිරීමෙන් අසාමාන්‍ය ඉහළ යෑම් (anomalies) හඳුනාගත හැක.

5

Multiplication

Each entry of C = AB is the dot product of a row of A with a column of B:

cij = ai1b1j + ai2b2j + … + ainbnj
  • (m×n)·(n×p) gives an m×p matrix.
  • Not commutative: AB ≠ BA in general.
  • Associative: (AB)C = A(BC). Transpose: (AB)ᵀ = BᵀAᵀ.
Plain English: to get one box of the answer, take a row from the first matrix and a column from the second. Multiply the pairs in order (first×first, second×second…), then add them up. Repeat for every box. This is harder than addition, so go slowly.
Size rule: the number of columns in A must equal the number of rows in B (the “inner numbers” match). Example: 2×3 times 3×4 works and gives 2×4.
Worked example

A = [[2,1],[0,3]], B = [[1,4],[2,−1]]. Then c11 = 2·1 + 1·2 = 4, c12 = 2·4 + 1·(−1) = 7, c21 = 0·1 + 3·2 = 6, c22 = 0·4 + 3·(−1) = −3, so AB = [[4,7],[6,−3]]. Load these into the Matrix lab and press A × B to see every dot product.

🐍 Why this matters for Python

Matrix multiplication is three nested loops (or a sum inside a comprehension). Writing it once yourself shows why it is slow and why NumPy exists.

💻 Software engineering
  • Neural networks are chains of matrix multiplications
  • 3D graphics and games transform every vertex with a matrix product
🛡️ Cybersecurity
  • The Hill cipher encrypts text by multiplying with a key matrix (mod 26)
  • Powers of an adjacency matrix count paths between hosts, useful for attack-path analysis
🐍 Python example
def matmul(A, B):
    n, m, p = len(A), len(B), len(B[0])
    return [[sum(A[i][k] * B[k][j] for k in range(m))
             for j in range(p)] for i in range(n)]

A = [[2, 1], [0, 3]]
B = [[1, 4], [2, -1]]
print(matmul(A, B))   # [[4, 7], [6, -3]]
සිංහල විස්තරය

ගුණ කිරීම ක්‍රියා කරන ආකාරය: ප්‍රතිඵල matrix එකේ එක් අගයක් ලබා ගැනීමට A හි පේළියක් සහ B හි තීරුවක් ගන්න. අනුරූප අගයන් එකිනෙක ගුණ කර (පළමුව×පළමුව, දෙවැන්න×දෙවැන්න...) ඒවා එකතු කරන්න. උදා: A = [[2,1],[0,3]], B = [[1,4],[2,−1]] සඳහා c₁₁ = 2·1 + 1·2 = 4, c₁₂ = 2·4 + 1·(−1) = 7, c₂₁ = 0·1 + 3·2 = 6, c₂₂ = 0·4 + 3·(−1) = −3.

නීති: A හි තීරු ගණන B හි පේළි ගණනට සමාන විය යුතුය (අභ්‍යන්තර සංඛ්‍යා සමාන). (m×n) × (n×p) = m×p. AB සහ BA සාමාන්‍යයෙන් සමාන නොවේ — ගුණ කිරීමේ අනුපිළිවෙල වැදගත් ය. (AB)ᵀ = BᵀAᵀ වේ.

Python සහ ක්ෂේත්‍රය: Python වලදී for loop තුනකින් මෙය ලිවිය හැක; එය ඉතා මන්දගාමී බව දැනගත් විට NumPy වැනි library වල වැදගත්කම වැටහේ. Neural network එකක් යනු matrix ගුණ කිරීම් මාලාවකි. Cybersecurity වලදී Hill cipher මගින් අකුරු සංඛ්‍යා බවට හරවා key matrix එකකින් ගුණ කර (mod 26) සංකේතනය කරයි. තවද network එකක adjacency matrix එක තමා සමඟම ගුණ කිරීමෙන් hosts අතර මාර්ග ගණන සොයා ගත හැක.

6

Determinant & inverse

Determinant
  • 2×2: det [[a,b],[c,d]] = ad − bc
  • 3×3: expand along row 1: a(ei − fh) − b(di − fg) + c(dh − eg)
  • det = 0 ⇒ matrix is singular (no inverse). |det| is the area/volume scaling factor.
Inverse
  • A⁻¹ exists only if det(A) ≠ 0, and AA⁻¹ = A⁻¹A = I.
  • 2×2: A⁻¹ = (1/(ad − bc)) · [[d, −b],[−c, a]]
  • Larger: A⁻¹ = (1/det A) · adj(A). Also (AB)⁻¹ = B⁻¹A⁻¹.
Try it: put [[2,1],[5,3]] in A and press det(A) then A⁻¹. det = 1, so the inverse is [[3,−1],[−5,2]].
🐍 Why this matters for Python

Determinant and inverse become two small functions. The check det == 0 is exactly the guard that stops a divide-by-zero crash.

💻 Software engineering
  • Checking det ≠ 0 before inverting avoids crashes and nonsense results
  • The determinant is the area (or volume) scale factor of a transformation
🛡️ Cybersecurity
  • A Hill cipher key matrix must be invertible (mod 26) or messages cannot be decrypted
  • Decryption is literally multiplying by the inverse matrix
🐍 Python example
def det2(M):
    return M[0][0] * M[1][1] - M[0][1] * M[1][0]

def inv2(M):
    d = det2(M)
    if d == 0:
        raise ValueError("singular: no inverse")
    return [[ M[1][1] / d, -M[0][1] / d],
            [-M[1][0] / d,  M[0][0] / d]]

print(det2([[2, 1], [5, 3]]))   # 1
print(inv2([[2, 1], [5, 3]]))   # [[3.0, -1.0], [-5.0, 2.0]]
සිංහල විස්තරය

Determinant (නිශ්චායකය): 2×2 matrix [[a,b],[c,d]] සඳහා det = ad − bc. 3×3 සඳහා පළමු පේළිය ඔස්සේ පුළුල් කරයි: a(ei − fh) − b(di − fg) + c(dh − eg). det = 0 නම් matrix එක singular වන අතර එයට inverse නොමැත. Determinant හි නිරපේක්ෂ අගයෙන් රූපයක වර්ගඵලය වෙනස් වන සාධකය දැක්වේ.

Inverse (ප්‍රතිලෝම): A⁻¹ ඇත්තේ det(A) ≠ 0 නම් පමණි; A × A⁻¹ = I වේ. 2×2 සඳහා A⁻¹ = (1/(ad − bc)) × [[d, −b],[−c, a]]. උදා: [[2,1],[5,3]] හි det = 6 − 5 = 1, ඒ නිසා inverse = [[3,−1],[−5,2]]. (AB)⁻¹ = B⁻¹A⁻¹ වේ.

Python සහ ක්ෂේත්‍රය: Python වලදී inverse ගණනය කිරීමට පෙර det == 0 දැයි පරීක්ෂා කිරීම, 0 න් බෙදීමේ දෝෂය (division by zero) වළක්වයි. Cybersecurity වලදී Hill cipher හි key matrix එක mod 26 යටතේ inverse ඇති එකක් විය යුතුය; එසේ නොවේ නම් decrypt කළ නොහැක. Decryption යනු inverse matrix එකෙන් ගුණ කිරීමයි.

7

Linear systems

A system like 2x + y = 5, x + 3y = 10 becomes AX = B with A = [[2,1],[1,3]], X = [x,y]ᵀ, B = [5,10]ᵀ. If A is invertible then X = A⁻¹B.

|
|
ax + by = c, dx + ey = f
🐍 Why this matters for Python

Solving AX = B is how programs find unknown values from several linear conditions. NumPy does it in one call, but underneath it is the inverse idea (or Cramer's rule) you just learned.

💻 Software engineering
  • Linear systems appear in simulations, resource planning and regression (curve fitting)
  • Knowing when there is no unique answer (det = 0) prevents silent bugs
🛡️ Cybersecurity
  • A known-plaintext attack on the Hill cipher solves a linear system to recover the key
  • Linear models estimate risk scores from several measured signals
🐍 Python example
# 2x + y = 5  and  x + 3y = 10   (Cramer's rule)
a, b, c = 2, 1, 5
d, e, f = 1, 3, 10
det = a * e - b * d
x = (c * e - b * f) / det
y = (a * f - c * d) / det
print(x, y)   # 1.0 3.0
සිංහල විස්තරය

රේඛීය සමීකරණ පද්ධති: 2x + y = 5 සහ x + 3y = 10 වැනි සමීකරණ දෙකක් AX = B ලෙස ලියයි: A = [[2,1],[1,3]], X = [x, y]ᵀ, B = [5, 10]ᵀ. A හි inverse ඇත්නම් X = A⁻¹B වේ.

උදාහරණය: det A = 6 − 1 = 5; A⁻¹ = (1/5)[[3,−1],[−1,2]]; X = (1/5)[3·5 − 1·10, −1·5 + 2·10] = [1, 3]. එනම් x = 1, y = 3. පරීක්ෂාව: 2(1) + 3 = 5 සහ 1 + 3(3) = 10 — නිවැරදි ය. det = 0 නම් අනන්‍ය විසඳුමක් නොමැත.

Python සහ ක්ෂේත්‍රය: Python වලදී NumPy හි numpy.linalg.solve එකෙන් මෙය එක් පේළියකින් කළ හැක; නමුත් එහි පසුපස ඇත්තේ ඔබ ඉගෙන ගත් inverse අදහසයි. Cybersecurity වලදී Hill cipher එකට known-plaintext ප්‍රහාරයක් යනු key එක සොයා ගැනීමට රේඛීය සමීකරණ විසඳීමකි. තවද risk score ගණනය කිරීමේ රේඛීය මොඩල ද මෙයින් ගොඩනැගේ.

2D transformations

A 2×2 matrix transforms every point (x, y) by multiplying. Drag the sliders; the blue house is the transformed shape. M = Rotation · Shear · Scale.

Rotate °0
Scale x1
Scale y1
Shear x0
Rotation by θ: [[cos θ, −sin θ],[sin θ, cos θ]]. Scale: [[sx,0],[0,sy]]. The determinant of M tells you how the area changes (negative = mirrored).
🐍 Why this matters for Python

Moving, rotating and scaling shapes is multiplying every point by a small matrix. Python's math module gives you sin and cos.

💻 Software engineering
  • UI animation, games and image editors rotate and scale with matrices
  • CSS even has a matrix() transform
🛡️ Cybersecurity
  • Rotating and scaling images is used to normalise them for forensics and OCR
  • CAPTCHAs distort text with transforms; attackers try to undo them
🐍 Python example
import math

def rotate(p, deg):
    t = math.radians(deg)
    x, y = p
    return (x * math.cos(t) - y * math.sin(t),
            x * math.sin(t) + y * math.cos(t))

print([round(v, 6) for v in rotate((1, 0), 90)])   # [0.0, 1.0]
සිංහල විස්තරය

2D පරිණාමන (transformations): 2×2 matrix එකකින් (x, y) ලක්ෂ්‍යයක් ගුණ කළ විට නව ස්ථානයට ගමන් කරයි. භ්‍රමණය (rotation) θ කෝණයකින්: [[cos θ, −sin θ],[sin θ, cos θ]]. විශාල කිරීම (scale): [[sx, 0],[0, sy]]. Shear මගින් හැඩය ඇල කරයි.

සංයුක්ත පරිණාමන: පරිණාමන කිහිපයක් එක matrix එකකට ගුණ කර ඒකාබද්ධ කළ හැක — අනුපිළිවෙල වැදගත් ය (M = R·S යනු පළමුව S, ඉන්පසු R යෙදීමයි). Det M ඍණ නම් රූපය දර්පණ ප්‍රතිබිම්බයක් වේ.

Python සහ ක්ෂේත්‍රය: Python වල math.sin සහ math.cos භාවිතයෙන් ලක්ෂ්‍ය භ්‍රමණය කළ හැක. Software Engineering වලදී game එකක අක්ෂර චලනය, UI animation සහ image editor වල මෙය භාවිතා වේ. Cybersecurity වලදී forensic රූප සහ OCR සඳහා රූප සාමාන්‍යකරණය (rotate/scale) කිරීම සිදු කරයි; CAPTCHA වල අකුරු විකෘති කරන්නේ ද මෙවැනි පරිණාමන මගිනි.

Q1. Let A = [[2,1],[0,3]] and B = [[1,4],[2,−1]]. Find (a) A + B, (b) 2A − B, (c) AB, (d) BA. What does (c) vs (d) show? [6 marks]
Answer: (a) A + B = [[3,5],[2,2]] (b) 2A = [[4,2],[0,6]], so 2A − B = [[3,−2],[−2,7]] (c) AB = [[2·1+1·2, 2·4+1·(−1)],[0·1+3·2, 0·4+3·(−1)]] = [[4,7],[6,−3]] (d) BA = [[1·2+4·0, 1·1+4·3],[2·2+(−1)·0, 2·1+(−1)·3]] = [[2,13],[4,−1]] AB ≠ BA: matrix multiplication is not commutative.
Q2. Find det of M = [[2,0,1],[1,3,2],[1,1,4]]. Is M invertible? [4 marks]
Answer: Expand along row 1: det = 2(3·4 − 2·1) − 0(1·4 − 2·1) + 1(1·1 − 3·1) = 2(10) − 0 + 1(−2) = 20 − 2 = 18 Since det ≠ 0, M is invertible.
Q3. Find the inverse of A = [[4,7],[2,6]] and verify it. [4 marks]
Answer: det = 4·6 − 7·2 = 24 − 14 = 10 A⁻¹ = (1/10)[[6,−7],[−2,4]] = [[0.6,−0.7],[−0.2,0.4]] Check row 1 × col 1 of A·A⁻¹: 4(0.6) + 7(−0.2) = 2.4 − 1.4 = 1 ✓ (other entries give 0, 0, 1, so AA⁻¹ = I).
Q4. Solve 2x + y = 5 and x + 3y = 10 using a matrix inverse. [5 marks]
Answer: A = [[2,1],[1,3]], det = 6 − 1 = 5, A⁻¹ = (1/5)[[3,−1],[−1,2]] X = A⁻¹B = (1/5)[3·5 − 1·10, −1·5 + 2·10] = (1/5)[5, 15] = [1, 3] So x = 1, y = 3. Check: 2(1)+3 = 5 ✓, 1+3(3) = 10 ✓.
Q5. Using A and B from Q1, verify (AB)ᵀ = BᵀAᵀ. [3 marks]
Answer: AB = [[4,7],[6,−3]] so (AB)ᵀ = [[4,6],[7,−3]]. Bᵀ = [[1,2],[4,−1]], Aᵀ = [[2,0],[1,3]]. BᵀAᵀ = [[1·2+2·1, 1·0+2·3],[4·2+(−1)·1, 4·0+(−1)·3]] = [[4,6],[7,−3]] ✓ Equal.
Q6. Find the single matrix M that first scales x by 2 and then rotates 90° anticlockwise. Apply M to the point (1,1). [4 marks]
Answer: S = [[2,0],[0,1]], R = [[0,−1],[1,0]]. Apply S first, so M = R·S (order matters!) M = [[0·2+(−1)·0, 0·0+(−1)·1],[1·2+0·0, 1·0+0·1]] = [[0,−1],[2,0]] M(1,1) = (0·1 − 1·1, 2·1 + 0·1) = (−1, 2). Check: S(1,1) = (2,1); R(2,1) = (−1,2) ✓
