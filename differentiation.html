Overview

Differentiation answers one question: how fast is something changing right now? The answer is called the derivative. If you can read a speedometer, you already understand the idea.

Why developers need it
  • Machine learning: training a model means following derivatives downhill (gradient descent).
  • Optimisation: find the cheapest, fastest or biggest option.
  • Graphics & games: speed and acceleration come from derivatives of position.
  • Performance: how quickly does run-time grow as the input grows?

  • Read each section; every idea is explained in plain English first.
  • Play with the interactive tools (sliders and calculators).
  • Do the quiz, then the sample test on paper before opening the answers.
No maths background needed. You only need to be comfortable with x², fractions and negative numbers. Everything else is built up step by step.
🐍 Why this matters for Python

In Python you will often work with changing data. The derivative is the tool for asking 'how fast is it changing right now?'

💻 Software engineering
  • Optimisation, machine learning and game physics all rely on derivatives
  • Profilers and monitors report rates of change, not only totals
🛡️ Cybersecurity
  • A sudden rise in the rate of failed logins signals a brute-force attempt
  • ML-based threat detectors learn by following derivatives

requests = [100, 104, 110, 180, 400]   # requests per minute
rate = [b - a for a, b in zip(requests, requests[1:])]

2

Rate of change (the idea)

Start with a car journey

You drive 100 km in 2 hours. Your average speed is 100 ÷ 2 = 50 km/h. But your speedometer might say 80 right now. That reading is your instant speed, and finding it is exactly what differentiation does.

Slope = rise ÷ run
  • On a graph, slope (gradient) tells you how steep a line is: slope = change in y ÷ change in x.
  • For the straight line y = 2x + 1, the slope is always 2: every 1 step right, you go 2 up.
  • For a curve, the steepness changes from point to point. The derivative gives the slope at one exact point.
Squeezing the gap

Take f(x) = x² and look near x = 1. We find the slope of the line between x = 1 and a second point that gets closer and closer:

Second pointCalculationSlope
x = 2(4 − 1) ÷ (2 − 1)3
x = 1.5(2.25 − 1) ÷ 0.52.5
x = 1.1(1.21 − 1) ÷ 0.12.1
x = 1.01(1.0201 − 1) ÷ 0.012.01

The slopes are heading towards 2. So the slope of x² at x = 1 is 2. That is the derivative at that point.

Notation: the derivative of f is written f′(x) (say “f prime of x”) or dy/dx (say “dee y by dee x”). Both mean “the slope of the curve at x”.
🐍 Why this matters for Python

Average rate of change is just (change in output) ÷ (change in input). Writing it as a function shows how the 'instant' version is built.

💻 Software engineering
  • Profiling: average CPU use can hide short, sharp bursts
  • Rates (requests/second, errors/minute) are the core metrics of monitoring
🛡️ Cybersecurity
  • An hourly average of logins can hide a one-minute brute-force burst
  • The instant rate exposes the burst; the average hides it
🐍 Python example
def avg_rate(f, x1, x2):
    return (f(x2) - f(x1)) / (x2 - x1)

f = lambda x: x ** 2
print(avg_rate(f, 1, 2))              # 3.0
print(round(avg_rate(f, 1, 1.1), 4))  # 2.1

3

From average to instant slope

Pick a function and a point x₀. The red line joins the point to a second point a distance h away. As you shrink h, the red line swings into the green tangent (the line that just touches the curve). The slope of the tangent is the derivative.

1 1.20
The definition (first principles)

f′(x) = lim (h→0) [ f(x + h) − f(x) ] ÷ h

  • f(x + h) − f(x) is the rise between the two points; h is the run.
  • lim (h→0) means “let h get closer and closer to 0”.
Worked example: f(x) = x²
  • f(x + h) = (x + h)² = x² + 2xh + h²
  • f(x + h) − f(x) = 2xh + h²
  • Divide by h: (2xh + h²) ÷ h = 2x + h
  • Let h → 0: the h disappears, leaving f′(x) = 2x

So the slope of x² at any point is 2x. At x = 1 that is 2 (matching the table), at x = 3 it is 6. You will rarely need first principles after this; the rules in the next section are shortcuts.

🐍 Why this matters for Python

When you have a function but no formula for its derivative, Python can estimate it with a very small h. This is numerical differentiation.

💻 Software engineering
  • Numerical derivatives are used when the formula is unknown or messy
  • Too small an h causes floating-point rounding errors, so choose h carefully
🛡️ Cybersecurity
  • Slope of a traffic graph over time is used to trigger alerts
  • Smoothing and thresholds decide whether a rise is an attack or noise
🐍 Python example
def derivative(f, x, h=1e-6):
    return (f(x + h) - f(x)) / h

print(round(derivative(lambda x: x ** 2, 3), 3))   # 6.0
සිංහල විස්තරය

සාමාන්‍ය බෑවුමේ සිට ක්ෂණික බෑවුමට: වක්‍රය මත P ලක්ෂ්‍යයක් සහ එයින් h දුරින් Q ලක්ෂ්‍යයක් ගන්න. P, Q යා කරන රේඛාව (secant) ගේ බෑවුම = (f(x+h) − f(x)) ÷ h. h කුඩා කරන විට මෙම රේඛාව වක්‍රය ස්පර්ශ කරන tangent (ස්පර්ශක) රේඛාවට ළඟා වේ. Tangent හි බෑවුම තමයි ව්‍යුත්පන්නය.

පළමු මූලධර්මය (first principles): f′(x) = lim (h→0) [f(x+h) − f(x)] ÷ h. f(x) = x² සඳහා: (x+h)² − x² = 2xh + h²; h න් බෙදූ විට 2x + h; h → 0 වන විට f′(x) = 2x. එනම් x = 3 හිදී බෑවුම 6 වේ.

Python සහ ක්ෂේත්‍රය: සූත්‍රයක් නොමැති විට Python වලදී h = 0.000001 වැනි කුඩා අගයක් භාවිතයෙන් ව්‍යුත්පන්නය ආසන්නව ගණනය කළ හැක. නමුත් h අතිශය කුඩා (1e-16) කළහොත් floating-point දෝෂ නිසා ප්‍රතිඵලය වැරදේ — මෙය programmers දැන සිටිය යුතු කරුණකි. Cybersecurity වලදී traffic ප්‍රස්තාරයක බෑවුම බලා හදිසි ඉහළ යෑම් සඳහා alert පනවයි.

Basic rules

The power rule (the one you will use most): bring the power down in front, then reduce the power by 1.
d/dx ( a·xⁿ ) = a·n·xⁿ⁻¹
  • x⁵ → 5x⁴  |  3x⁴ → 12x³  |  x → 1  |  x² → 2x
  • Constants disappear: the derivative of a plain number like 7 is 0 (a flat line has slope 0).
  • Add and subtract term by term: differentiate each piece separately.
Worked example: f(x) = 4x³ − 5x² + 2x − 7
  • 4x³ → 4×3 = 12, power 3−1 = 2 → 12x²
  • −5x² → −5×2 = −10, power 1 → −10x
  • 2x → 2×1 = 2, power 0 → 2
  • −7 → 0

බලය රීතිය (power rule): බලය ඉදිරියට ගෙන එන්න, පසුව බලය 1කින් අඩු කරන්න. d/dx (a·xⁿ) = a·n·xⁿ⁻¹. උදා: x⁵ → 5x⁴; 3x⁴ → 12x³. නියත අගයක ව්‍යුත්පන්නය 0 ය (සමතල රේඛාවක බෑවුම 0). පද එකින් එක වෙන වෙනම අවකලනය කරයි.

උදාහරණය: f(x) = 4x³ − 5x² + 2x − 7 → 12x² − 10x + 2. මූල සහ භාග බලයන් ලෙස ලියා ගන්න: √x = x^(1/2), 1/x = x⁻¹. eˣ, ln x, sin x, cos x හි ව්‍යුත්පන්න ද මතක තබා ගන්න (eˣ → eˣ, ln x → 1/x, sin x → cos x, cos x → −sin x).

Python සහ ක්ෂේත්‍රය: Python වලදී බහුපද (polynomial) dictionary එකක් ලෙස ගබඩා කර power rule එක loop එකකින් යෙදිය හැක; autograd library ද මෙයමයි. Cybersecurity වලදී brute force ප්‍රහාරයක් සඳහා වැයවන කාලය key දිග වැඩි වන විට කොතරම් වේගයෙන් වැඩි වේද යන්න (වර්ධන වේගය) විශ්ලේෂණයට මෙම අදහස උපකාරී වේ.

5

Product, quotient & chain rules

These three rules handle functions built from other functions. Learn when to use each one.

Product rule: two things multiplied

d/dx (u·v) = u′·v + u·v′

  • Say it: “derivative of the first × second, plus first × derivative of the second”.
  • Example: y = x²·eˣ. Here u = x², v = eˣ. Then y′ = 2x·eˣ + x²·eˣ = x·eˣ(2 + x).
Quotient rule: one thing divided by another

d/dx (u ÷ v) = ( u′·v − u·v′ ) ÷ v²

  • Example: y = (x² + 1) ÷ (x − 1). u = x² + 1, u′ = 2x, v = x − 1, v′ = 1.
  • y′ = [2x(x − 1) − (x² + 1)·1] ÷ (x − 1)² = (x² − 2x − 1) ÷ (x − 1)².
  • Order matters on top: u′v minus uv′.
Chain rule: a function inside a function

d/dx f(g(x)) = f′(g(x)) · g′(x)

  • Plain English: differentiate the outside, keep the inside the same, then multiply by the derivative of the inside.
  • Example 1: y = (3x + 2)⁵. Outside: power 5 → 5(3x + 2)⁴. Inside 3x + 2 has derivative 3. So y′ = 15(3x + 2)⁴.
  • Example 2: y = sin(x²). Outside: sin → cos(x²). Inside x² has derivative 2x. So y′ = 2x·cos(x²).
  • Example 3: y = e2x gives 2·e2x.
If you see…Use…
A × B (both contain x)Product rule
A ÷ B (both contain x)Quotient rule
Brackets raised to a power, or sin( ), e( ), ln( ) of something more than just xChain rule
🐍 Why this matters for Python

Product, quotient and chain rules are what automatic-differentiation libraries apply behind the scenes. You can check the chain rule numerically in a few lines.

💻 Software engineering
  • Neural networks are functions inside functions; backpropagation is the chain rule
  • Cost and rate formulas often multiply or divide changing quantities
🛡️ Cybersecurity
  • Adversarial attacks use gradients to find tiny input changes that fool an ML detector
  • Understanding this helps you judge how robust a model really is
🐍 Python example
import math
f = lambda x: math.sin(x ** 2)
exact = lambda x: 2 * x * math.cos(x ** 2)   # chain rule
h, x = 1e-6, 1.0
approx = (f(x + h) - f(x)) / h
print(round(approx, 3), round(exact(x), 3))   # 1.081 1.081

ගුණිත රීතිය (product rule): u × v සඳහා (uv)′ = u′v + uv′. උදා: x²·eˣ → 2x·eˣ + x²·eˣ. බෙදීමේ රීතිය (quotient rule): (u/v)′ = (u′v − uv′) ÷ v². උඩින් u′v ඍණ uv′ — අනුපිළිවෙල වැදගත්.

දාම රීතිය (chain rule): f(g(x)) සඳහා ව්‍යුත්පන්නය = f′(g(x)) · g′(x). සරලව: පිටත ශ්‍රිතය අවකලනය කරන්න, ඇතුළත එලෙසම තබන්න, පසුව ඇතුළත ශ්‍රිතයේ ව්‍යුත්පන්නයෙන් ගුණ කරන්න. උදා: (3x + 2)⁵ → 15(3x + 2)⁴; sin(x²) → 2x·cos(x²). ආකෘතිය හඳුනා ගැනීමට: A×B නම් product, A÷B නම් quotient, වරහන් බලයක/ශ්‍රිතයක් ඇතුළත නම් chain.

Python සහ ක්ෂේත්‍රය: ඉහත කේතයේ chain rule එකෙන් ලැබෙන නිවැරදි අගය සහ කුඩා h මගින් ලැබෙන ආසන්න අගය සමාන වන බව දැකිය හැක. Neural network එකක් ස්ථර කිහිපයක් එක ශ්‍රිතයක් ඇතුළත තවත් එකක් ලෙස සම්බන්ධ වූවකි; backpropagation යනු chain rule එක ස්ථර හරහා යෙදීමයි. Cybersecurity වලදී adversarial ප්‍රහාර (FGSM වැනි) gradient භාවිතයෙන් ආදානයට ඉතා කුඩා වෙනස්කම් කර ML detector එක රැවටීමට උත්සාහ කරයි.

Maximum & minimum problems

Because f′ = 0 means a flat tangent, the top of a hill or the bottom of a valley always has f′ = 0. That gives a method:

  1. Write the thing you want to maximise or minimise as a formula in one variable.
  2. Differentiate it and set f′(x) = 0. Solve for x. These are the stationary points.
  3. Second derivative test: work out f″(x), then check at each point: f″ > 0 → minimum (valley, curves up); f″ < 0 → maximum (hill, curves down).
  4. Substitute back to get the actual value, and answer in words.
Worked example: biggest field

A farmer has 40 m of fencing for a rectangular field. What size gives the largest area?

  • Let width = x. Then length = 20 − x (because 2·width + 2·length = 40).
  • Area A = x(20 − x) = 20x − x²
  • A′ = 20 − 2x = 0 → x = 10
  • A″ = −2, which is negative → maximum
  • Width 10 m, length 10 m, area 100 m²: a square is best.
Use the Function lab above: set a = 1, b = −6, c = 9, d = 1 and see the peak at x = 1 and valley at x = 3 appear on the graph.
🐍 Why this matters for Python

Many programs must pick the best value: the cheapest, fastest or biggest. Calculus finds it directly instead of trying every option.

💻 Software engineering
  • Minimising cost or latency, balancing load across servers
  • Libraries such as SciPy optimise using exactly these ideas
🛡️ Cybersecurity
  • Choosing a detector threshold is a trade-off between false alarms and missed attacks
  • Defenders optimise security against usability and cost
🐍 Python example
area = lambda x: x * (20 - x)
best = max(range(0, 21), key=area)
print(best, area(best))   # 10 100
සිංහල විස්තරය

උපරිම/අවම ගැටළු: කඳු මුදුනක හෝ නිම්නයක තිබෙන ස්පර්ශකය සමතල වන නිසා f′ = 0 වේ. පියවර: (1) උපරිම/අවම කළ යුතු දේ එක විචල්‍යයක ශ්‍රිතයක් ලෙස ලියන්න; (2) අවකලනය කර f′(x) = 0 විසඳන්න; (3) දෙවන ව්‍යුත්පන්න පරීක්ෂාව: f″ > 0 නම් අවම, f″ < 0 නම් උපරිම; (4) අගය ආදේශ කර වචනයෙන් පිළිතුර දෙන්න.

උදාහරණය: වැටක් මීටර් 40ක් ඇති ගොවියෙකුට විශාලතම වර්ගඵලය ලැබෙන කොටුව: පළල x, දිග 20 − x; වර්ගඵලය A = 20x − x²; A′ = 20 − 2x = 0 → x = 10; A″ = −2 (ඍණ) → උපරිමයයි. මීටර් 10 × 10, වර්ගඵලය 100 m².

Python සහ ක්ෂේත්‍රය: ඉහත කේතය අගයන් සියල්ල අත්හදා බලා (brute force) හොඳම අගය ගනී; කැල්කියුලස් මගින් ඒ අගය (x = 10) කෙලින්ම සොයා ගත හැක, එය වේගවත්. Software Engineering වලදී පිරිවැය අවම කිරීම, server භාර බෙදීම; Cybersecurity වලදී detector එකේ threshold අගය තෝරා ගැනීම (false alarm සහ මග හැරීම් අතර සමතුලිතතාව) මෙවැනි optimisation ගැටළුවකි.

8

Developer corner: gradient descent

Training a machine-learning model means finding the input that makes an error function as small as possible. Gradient descent does this by repeatedly stepping downhill, using the derivative to know which way is down.

The update rule

new x = x − (learning rate) × f′(x)

  • If f′ is positive, the curve goes up to the right, so move left (subtract).
  • If f′ is negative, move right.
  • The learning rate sets the step size. Too small is slow; too big overshoots.

Minimise f(x) = (x − 3)² + 1, so f′(x) = 2(x − 3). The minimum is at x = 3.

0.20
Try a learning rate of 1.1: each step overshoots further than the last and x flies away. This is why choosing the learning rate matters in real training.
🐍 Why this matters for Python

This loop is the heart of machine-learning code in Python: compute the slope, step downhill, repeat.

💻 Software engineering
  • Training linear regression and neural networks
  • Choosing the learning rate is a real engineering decision
🛡️ Cybersecurity
  • Training spam, malware and intrusion detectors
  • Attackers also use gradients to find inputs that fool a model
🐍 Python example
x = 8.0
lr = 0.2                 # learning rate
for step in range(10):
    grad = 2 * (x - 3)   # derivative of (x - 3)**2 + 1
    x = x - lr * grad
print(round(x, 4))       # 3.0302  (heading towards 3)
සිංහල විස්තරය

Gradient descent: machine learning වලදී model එකක error එක අවම කළ හැකි අගය සොයා ගැනීමට, ව්‍යුත්පන්නය භාවිතයෙන් පහළට පියවරෙන් පියවර යයි. යාවත්කාලීන රීතිය: new x = x − (learning rate) × f′(x). f′ ධන නම් වමට, ඍණ නම් දකුණට ගමන් කරයි.

Learning rate: පියවර ප්‍රමාණය තීරණය කරයි. අඩු නම් මන්දගාමී; වැඩි නම් මුදුනින් පැන යයි. f(x) = (x − 3)² + 1 සඳහා 1.1 වැනි විශාල අගයක් දුන් විට x හැම පියවරකම ඈතට යයි (diverge). මෙම tool එකේ slider එක 1.1 කර උත්සාහ කරන්න.

Python සහ ක්ෂේත්‍රය: Python වල for loop එකකින් මෙය ලිවිය හැක — Python ML කේතයේ හදවත මෙයයි. පියවර 10කින් පසු x ≈ 3.0302 වන අතර අවමය (3) ට ළං වේ. Software Engineering: linear regression, neural network පුහුණු කිරීම. Cybersecurity: spam, malware, intrusion detector පුහුණු කිරීම; ප්‍රහාරකයන් ද gradient භාවිතයෙන් මොඩල රැවටීමට උත්සාහ කරයි.

Sample test + answers

Total 30 marks. Attempt each question on paper first, then click to reveal the full worked answer (marks shown in brackets).

Q1. (a) Differentiate f(x) = 4x³ − 5x² + 2x − 7. (b) Differentiate g(x) = x⁻² + 3√x. (c) Differentiate h(x) = 6/x³. [6 marks]
Worked answer: (a) 12x² − 10x + 2 [2] (b) Rewrite 3√x as 3x^(1/2). g′(x) = −2x⁻³ + (3/2)x^(−1/2) = −2/x³ + 3/(2√x) [2] (c) Rewrite h(x) = 6x⁻³. h′(x) = −18x⁻⁴ = −18/x⁴ [2]
Q2. Use first principles to show that the derivative of f(x) = x² is 2x. [4 marks]
Worked answer: f′(x) = lim (h→0) [ (x + h)² − x² ] ÷ h [1] = lim [ x² + 2xh + h² − x² ] ÷ h = lim (2xh + h²) ÷ h [1] = lim (2x + h) [1] As h → 0 this becomes 2x. ✓ [1]
Q3. (a) Differentiate y = x²·eˣ. (b) Differentiate y = (x² + 1) ÷ (x − 1). [5 marks]
Worked answer: (a) Product rule with u = x², v = eˣ: y′ = 2x·eˣ + x²·eˣ = x·eˣ(2 + x) [2] (b) Quotient rule with u = x² + 1, v = x − 1: y′ = [2x(x − 1) − (x² + 1)] ÷ (x − 1)² [2] = (2x² − 2x − x² − 1) ÷ (x − 1)² = (x² − 2x − 1) ÷ (x − 1)² [1]
Q4. Use the chain rule to differentiate (a) y = (3x + 2)⁵ and (b) y = sin(x²). [4 marks]
Worked answer: (a) Outside: 5(3x + 2)⁴. Inside derivative: 3. y′ = 15(3x + 2)⁴ [2] (b) Outside: cos(x²). Inside derivative: 2x. y′ = 2x·cos(x²) [2]
Q5. Find the stationary points of f(x) = x³ − 6x² + 9x + 1 and decide whether each is a maximum or a minimum. [6 marks]
Worked answer: f′(x) = 3x² − 12x + 9 = 3(x² − 4x + 3) = 3(x − 1)(x − 3) [2] Set f′ = 0: x = 1 or x = 3 [1] f″(x) = 6x − 12 [1] f″(1) = −6 < 0 → maximum, f(1) = 1 − 6 + 9 + 1 = 5, point (1, 5) f″(3) = 6 > 0 → minimum, f(3) = 27 − 54 + 27 + 1 = 1, point (3, 1) [2]
Q6. A farmer has 40 m of fencing to enclose a rectangular field. Find the dimensions that give the largest area, and state that area. [5 marks]
Worked answer: Let width = x, so length = 20 − x. [1] Area A = x(20 − x) = 20x − x² [1] A′ = 20 − 2x = 0 → x = 10 [1] A″ = −2 < 0, so this is a maximum [1] Dimensions 10 m × 10 m, maximum area = 100 m² [1]

  • Any answer can become an automatic check with assert
🛡️ Cybersecurity

  • Re-deriving a result by hand is how you spot a faulty script
🐍 Python example
def derivative(f, x, h=1e-6):
    return (f(x + h) - f(x)) / h

# Exam answer: f(x) = x^3 - 6x^2 + 9x + 1 has f'(1) = 0
f = lambda x: x ** 3 - 6 * x ** 2 + 9 * x + 1
assert abs(derivative(f, 1)) < 1e-4
print("stationary at x = 1")
